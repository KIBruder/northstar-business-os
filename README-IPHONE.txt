NORTHSTAR – iPhone GitHub-Upload

Lege auf GitHub ein Repository an und lade ALLE Dateien aus diesem Ordner direkt in das Repository-Hauptverzeichnis hoch.
Keine Unterordner anlegen. Die Dateinamen müssen unverändert bleiben.

Danach im Repository:
Settings > Pages > Deploy from a branch > Branch: main > Folder: / (root) > Save

Warte, bis GitHub Pages die Website veröffentlicht hat. Öffne die angezeigte HTTPS-Adresse in Safari.
Für die Installation: Teilen > Zum Home-Bildschirm.

Hinweis: Die erste Version ist ein lokaler Prototyp. Es gibt noch keine KI-Anbindung, keine Synchronisierung zwischen Geräten und noch keine Verschlüsselung der lokalen Daten.
